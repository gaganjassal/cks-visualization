Placement notes

Nesting shows scope of concern, not physical placement. A Deployment is a cluster object that creates Pods, and those Pods are scheduled onto nodes. It sits above Pod here because it is where you declare the manifest that policy checks.

Gatekeeper, Kyverno and Pod Security Admission are enforced by the API server, but they act on Deployment and Pod manifests, so they are filed under Deployment. NetworkPolicy selects Pods, so it is filed under Pod.

Domain tags follow the CKS curriculum as I understand it. Check the current curriculum from the Linux Foundation, since topics move between domains from time to time. Commands are exam-style reminders, not complete runbooks.
